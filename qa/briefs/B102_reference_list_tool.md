# Builder brief B102: a reference-list generator in Elsevier Harvard form (decision 98)

Rules: plain language; no em dashes in prose (the reference list itself uses the journal's en dash in page ranges). No git; no subagents; no network. Write only `qa/tools/make_references.py`, `papers/A_results/draft/references.md`, `papers/B_methods/draft/references.md` and `qa/reports/B102_reference_list_tool.md`. Read `papers/B_methods/JOURNAL_REQUIREMENTS.md` (References) first.

The script, run as `python3 qa/tools/make_references.py A|B`, must: (1) collect every literature register id cited in the paper's claims csvs (`papers/*/draft/*_claims.csv`, column `register_id`; several ids may sit in one cell, separated by `;` or `,`; ignore A- and B- and D-series ids) and in `supplementary_claims.csv`, and also scan the section files for "Author Year" citations whose register row it can identify, reporting any citation in the prose with no register id behind it; (2) for each id, build one entry from `qa/literature_register.csv` in Elsevier Harvard form: surnames and initials, year, title, journal abbreviated (keep the full journal name if no abbreviation is known, and list it for a later pass), volume, issue in parentheses where the register has it, pages or article number, DOI as https://doi.org/...; books with edition, publisher, place; chapters with "in:" editors (Eds.), book, publisher, pp.; reports with issuer, series and place; web pages with the full URL and "(accessed <date>)"; the thesis as a thesis; datasets with [dataset] and software with [software]; (3) parse what it can from the register's `title` field (which holds the citation in a loose form: authors, year, quoted title, venue, volume(issue): pages, doi) and mark every entry it could not parse fully with "[CHECK: <what is missing>]" rather than guessing; (4) sort alphabetically then chronologically, and add a, b letters to same-author same-year entries; (5) write the list with a header line giving the count and the count of CHECK entries, and print the ids with no register row and the register rows cited only "as reported in" (so the list can say which works were not seen). Deterministic output; two runs identical.

Report: the counts per paper; every CHECK entry and what it lacks; prose citations with no register id; the journal abbreviations you did not know; and "Wrong-value check:" with one deliberate example of a malformed entry the script would flag, marked as an example.
