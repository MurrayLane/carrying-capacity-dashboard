# Builder brief B151: the submission build (manuscript files, figure files, highlights, statements)

Rules: plain language; no em dashes anywhere; no time words. No git; no subagents; no network (pandoc and matplotlib are installed; no package installs). Nothing is uploaded, tagged, sent or published. Write only under `papers/SUBMISSION/build/` (new), the figure scripts under `analysis/figures_2025/paper_A/` and `paper_B/` (one change only: each script also saves a PDF beside its PNG and SVG, same size, via matplotlib's `savefig`, with fonts embedded as Type 42), `papers/A_results/draft/acknowledgements_and_statements.md` and `papers/B_methods/draft/acknowledgements_and_statements.md` (new; placeholders only, no names), `qa/tools/build_submission.sh` (new), and `qa/reports/B151_submission_build.md`. Do not edit any section file, claims csv, register or `figures.csv`.

Inputs: `papers/SUBMISSION/checklist_A.md`, `checklist_B.md`, `BEFORE_SUBMIT.md`, `papers/B_methods/JOURNAL_REQUIREMENTS.md`; the tools `qa/tools/assemble_draft.py` (`--submission` writes `paper_<P>_submission.md`: title only, no working headings, drafter notes or comments) and `qa/tools/make_references.py` (`--style springer` for A; `--no-ids` drops the id comments); the figure scripts and `figures.csv` of each paper.

1. **`qa/tools/build_submission.sh`:** one script that, from the repository root, (a) runs `assemble_draft.py A --submission` and `B --submission`; (b) regenerates both reference lists with `--no-ids` (A with `--style springer`); (c) appends the reference list and, for Paper A, the declarations file to the submission markdown in the journal's order (title, abstract, keywords, main text, declarations, references, then a separate supplement file); (d) converts each to `.docx` with pandoc (a reference docx is not required; default styles) and also to a `.md` copy; (e) copies the figure PDFs, PNGs and the supplement into `papers/SUBMISSION/build/A/` and `build/B/` with journal-style names (`Fig1.pdf` ...); (f) writes Ecological Economics' separate `highlights.txt` (the five highlights only, no keywords) and Paper A's keywords line; (g) prints the word counts from `wordcount.py`, the abstract word counts, the highlight character counts and the list of "[" placeholders left in the built files; (h) runs idempotently (a second run gives identical files except pandoc's internal timestamps, which you set fixed with `--metadata date=` or strip).
2. **Figure PDFs:** add the PDF save to each figure script (the only edit), rerun every script, confirm the PNG and SVG are byte-identical to before (cmp) and the PDFs open (check with `python3 -c "import fitz"` if available, else `pdfinfo` if available, else file size and `%PDF` header).
3. **Acknowledgements and statements:** one file per paper with the headings each journal asks for (Ecological Economics: Acknowledgements, Funding, Declaration of competing interest, Data availability, Declaration of generative AI; Springer: Acknowledgements, Funding, Competing interests, Ethics approval (not applicable: no human or animal subjects), Data availability, AI declaration), each with the text from `papers/DECLARATIONS.md` where it exists and "[author to supply]" elsewhere, no names; the build script includes them.
4. Run the build; report the counts it prints, the placeholders found, the files written, the docx sizes, and anything the journals ask for that the build cannot supply; "Wrong-value check:" with one count deliberately copied from `checklist_B.md` and compared with the build's own count, marked as an example.
