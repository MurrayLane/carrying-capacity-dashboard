# B49 report: gap attribution for the method tests (decision 34)

**What was done.** `analysis/method_tests_2025/gap_attribution.py` runs the HALF, Simpson (build 3), Cassidy and Henry and Godden recipes as side calculations, with the output sections of the method scripts cut from the code before it runs and one candidate cause changed at a time; it writes `analysis/method_tests_2025/gap_attribution.csv` (161 rows) and nothing else. Every other csv in the folder is byte-identical before and after (md5 checked). The table is generated by a new `t_gap_attribution` in `make_readme_tables.py` and sits in a new README section "Gap attribution". The README block was inserted from `block()` for this table alone; `--write` was not run, because it would restamp the commit line of every other table (README stamps `df9803e`, HEAD is `c0f6faa`).

Run: `python3 -I analysis/method_tests_2025/gap_attribution.py 'Production_Crops_Livestock_E_All_Data_(Normalized).csv'` (the FAOSTAT QCL bulk file of `qa/fao_bulk_hashes.csv`; the script checks the sha256). The bulk file is read because the folder's extracts hold neither 1996 to 1999 for Australia nor 1997 to 2003 for the Cassidy countries (`fao_qcl_countries.csv` holds 2011 and 2021 to 2023 only).

**Convention.** residual = published - this test (unrounded). Explained share = (figure with the cause - this test) / residual x 100. 100% closes, above 100% overshoots, negative widens. Shares of one residual do not add when causes interact.

Sources read: Alexander et al. 2016 and its supplement (pp. SI-1 to SI-5; paper pp. 89 to 90); ABS 4306.0 1991-92 (Table 1, Table 2 p. 8, technical notes pp. 21 to 22, ERP p. 25); Wackernagel 1994 thesis pp. 284 to 285, Table A2.3 (via `wackernagel_1994_food_factors.csv` and the page text); Henry and Godden 1995 Tables 2 to 5 (scan pp. 99 to 100); Foran and Poldy 2002 Table 2.5 and p. 63 with its ABS references; Cassidy et al. 2013 pp. 2 to 5.
