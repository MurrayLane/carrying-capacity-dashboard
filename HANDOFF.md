## Release chain (all `releases/<id>/release.json`)

**Method modules and the grid (2026-10-28).** Method changes are modules in `methods/<id>/method.json`, applied by a release's `methods` list to any data set (`methods/README.md`). The comparison is a grid of data vintage by method tier: published (thesis method, errors kept: `2011-corrected`, `2025-mirror` = `2025-fuel`), corrected (`2011-fixed`, `2025-fixed`: errors against the thesis's own sources, no judgement) and improved (`2011-improved`, `2025-improved`: corrections plus judgement-based changes). The lists are `CORRECTIONS` (`biodiesel-yield`, `beef-carcase-yield`) and `IMPROVED` (`reserve-pro-rata`, `recycling-stage`) in `analysis/comparison_2025/make_cells.py` (improved list confirmed by Murray 2026-10-28; separating corrections from improvements was Murray's go-ahead of my recommendation the same day). `resilience-loo` is not in either: its table is data of its own vintage and does not exist for 2011. `results/` holds every release evaluated for all 60 zones and both presets, `comparison_cells.csv` (the grid, with the path of steps from the published 2011 result to the improved 2025 result) and `method_effects.csv`; regenerate with `cd web && npm run results` (about 4 minutes). Papers read `results/` and nothing else (PUBLICATIONS.md).

Published as 2011 replicas: `2011` (as published), `2011-thesis`, `2011-corrected`. Updated method and data, each layer extends the one before and is tested alone: `2025-land` > `2025-population` > `2025-yields` > `2025-livestock` > `2025-consumption` > `2025-organic` > `2025-resilience` > `2025-fuel` > `2025-diet` (layer 9, 2026-10-29: the split of red meat among beef, lamb, veal and pork carried forward by the FAO series: beef 69.2% to 59.5%, lamb 17.9% to 23.1%, pork 10.9% to 15.6%; `analysis/consumption_2025/make_red_meat_mix.py`). ## Standing decisions (do not reopen)

* **TWO LINES OF ENQUIRY, ALWAYS (Murray, repeated 2026-10-28).** Line 1 mirrors the previous methodology: update the data with the existing process, so the 2011 comparison is like for like (releases that keep the thesis method). Line 2 explores new and improved methods: wherever the assistant can see how the process could have been done better (for example splitting recycling by stage, by destination and by what the law allows), it must explore that too, without being asked, and publish it as its own release or analysis. More than one option can be right; neither line replaces the other, and the second is not an optional extra. Each analysis folder says which line each result belongs to.

* Method frozen during the data refresh (SCOPE.md D1). If in doubt default to 2011; if 2011 is wrong record the corrected approach as an alternate 2011 release.
* Every method choice is published BOTH ways: the 2011 replica for the direct comparison AND the updated method and data (SCOPE.md D9).
* Recreate the 2011 zones first (D2); five zones with older boundaries are flagged. Two data windows: 2021 and 2025 (B9).
* Crops the ABS stopped reporting: the group-trend proxy, applied consistently (B10). Livestock: current herd totals on the 2010 class mix, otherwise 2011 (B12).
* A negative non-agricultural remainder is shown as zero. For Australia and the states only cropping and pasture land enter capacity (non-agricultural land absorbs the reserve and infrastructure); in 23 of the 60 zones (short term) and 18 (long term) the reserve and infrastructure settings change capacity.
* No forum, no blog; only the dashboard. Visual pages are done after the modelling is complete (SCOPE.md "Order and dependencies", item 7).
* Method updates that directly inform the data (new meta-analyses, E5) are done now. Contact address for the About page is held (`mc.lane@qut.edu.au` may not persist).
